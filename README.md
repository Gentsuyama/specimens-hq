# Specimens — abertura em HQ (protótipo)

Teste do formato de cutscene em quadrinhos para a abertura do jogo **Specimens**: quadros que aparecem um por vez,
formato de quadro pela emoção da cena, arte gerada no Google Flow e vozes do Gemini (Google AI Studio).

Abrir: https://gentsuyama.github.io/specimens-hq/

Clique, Espaço ou → avança; ← volta; Esc pula; S liga/desliga o som.
